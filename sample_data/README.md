# Sample data

- `sample_roll_decay_SIMULATED.csv` - **simulated** free roll decay of the empty v2 catamaran (linear model, zeta = 0.08, sensor noise 0.3 deg), same format as the MPU6050 logger (`t,roll,pitch`). Upload it in tab 4 to see the roll-decay analysis. It is not a measurement.
- Real measurements from the tank tests go in this folder as `testA_draught.csv`, `testB_inclining.csv`, `testC_decay_run1.csv` ... and are labelled **measured**.
